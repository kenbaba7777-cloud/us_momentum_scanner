# US Momentum & Breakout Scanner 🚀

Streamlit-App zum Scannen von US-Aktien nach kurzfristigen Momentum-, Relative-Strength-, Volumen- und Breakout-Signalen.

## Enthalten
- S&P 500
- Nasdaq-100
- Russell 2000 (best effort über aktuelle IWM-Holdings)
- Momentum Score 0–100
- 1D / 3D / 5D / 20D / 60D Momentum
- Relative Strength gegen SPY
- Volume Surge
- 20-Tage-Breakout
- Nähe zum 52-Wochen-Hoch
- Trend über 20/50/200 Tage
- Momentum-Beschleunigung
- Explosive-Setup-Watchlist

## Streamlit Cloud
1. Dateien in ein GitHub-Repository hochladen.
2. https://share.streamlit.io öffnen.
3. Create app.
4. Repository auswählen.
5. Branch: `main`
6. Main file: `app.py`
7. Deploy.

Keine API-Key-Eingabe nötig.

## Hinweis
Der Scanner findet technische Setups; er kann nicht vorhersagen, welche Aktie sicher stark steigen wird. Daten über Yahoo Finance/yfinance können verzögert sein und sind nicht für professionelle Echtzeit-Handelsentscheidungen garantiert.
